Simple Crud App using MongoDB Express Vue Node JS
It is built on the MEVN stack (MongoDB, Express, Vue.js, Node.js) and demonstrates a complete implementation of RESTful API architecture and frontend-backend separation.  FeaturesCreate (Add): Add new vocabulary words, translations, and optional image URLs.Read (View): Retrieve and display a comprehensive list of all saved vocabulary.Update (Edit): Modify existing entries to correct typos or update meanings.Delete (Remove): Delete vocabulary words from the database.Practice Mode: An interactive testing environment for active recall.Tech StackFrontend: Vue.js (Vue 3)  Backend: Node.js with Express.js  Database: MongoDB  API Communication: Axios (via custom API services)Project StructureThe repository is divided into two main directories to separate the client-side and server-side logic:  /backendContains the Node.js/Express API server.src/app.js: Main server entry point.  src/api/models/post.js: MongoDB schema definition.  src/api/routes/post.js: Express routing for API endpoints.  src/api/controllers/post.js: Business logic for handling CRUD requests.  /frontend  Contains the Vue.js user interface.src/App.vue & src/main.js: Vue application entry points.  src/views/: Contains page-level components (Posts.vue, NewPost.vue, EditPost.vue, TestPage.vue).  src/components/: Reusable UI components (PostForm.vue).  src/services/: API connection logic (Api.js, PostsService.js) to communicate with the backend.  src/router/index.js: Vue Router configuration for frontend navigation.  Setup & InstallationPrerequisitesNode.js installed on your machine.A running instance of MongoDB (local or MongoDB Atlas).1. Backend SetupOpen a terminal and navigate to the backend directory: cd backendInstall dependencies: npm installStart the Express server: npm startNote: Ensure your MongoDB connection string is properly configured in your backend environment variables or app configuration.2. Frontend SetupOpen a new terminal window and navigate to the frontend directory: cd frontendInstall dependencies: npm installStart the Vue development server: npm run serveOpen your browser and navigate to the local host address provided in the terminal (usually http://localhost:8080).
